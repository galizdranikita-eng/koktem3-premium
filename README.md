# Koktem-3 Premium IMED-style

Отдельный вариант PWA-приложения / сайта для сравнения со старыми версиями.

Что изменено:
- стиль ближе к дорогому сайту частной клиники;
- добавлены блоки «Оборудование» и «Новости»;
- сохранены русский и казахский языки;
- сохранены запись, мои записи, цены и админ-панель;
- демо-пароль администратора: `koktem3`.

Файлы для GitHub Pages:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

`koktem3-premium-imed`
